## Описание
Приложение позволяет сформировать поле, заполненное квадратными ячейками.

Число ячеек по ширине (горизонтали) в высоте (вертикали) задаётся пользователем в полях "W" (ширина) и "H" (высота) соответственно. 

Для ввода доступно множетсво натуральных чисел. Пользователь может ввести любое натуральное число, но чем больше число, тем больше время ожидания отрисовки.

Для получения изображения нужно нажать кнопку "Generate"; на белом пространстве слева от кнопки появится изображение с заданными характеристиками.

После того, как заполнится прогрессбар анализа лабиринта, если путь из точки А в точку B существует, то он будет найден. 
Для установки точки А нужно выбрать незакрашенный квадрат ЛКМ + Ctrl.
